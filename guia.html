Bem-vindo

O Sistema Web de Pareceres e Formulários Institucionais foi desenvolvido para apoiar a elaboração de pareceres técnicos e documentos administrativos da Coordenação de Concessões, Aposentadorias e Ações Judiciais.

A plataforma reúne modelos organizados por assunto e formulários eletrônicos, proporcionando maior padronização, agilidade e segurança na elaboração dos documentos.

Como utilizar o sistema
  1. Escolha a concessão

    2. Na página inicial, selecione a concessão correspondente ao processo administrativo que deseja analisar.

    Cada botão direciona para um conjunto de pareceres ou formulários relacionados à modalidade de concessão escolhida.

  2. Selecione o assunto do parecer ou do formulário

    3. Após acessar o módulo desejado, escolha o assunto correspondente à situação apresentada no processo.

  3. Preencha as informações

    4. Nos pareceres ou formulários automatizados, informe os dados solicitados conforme os dados do presentes no processo.

    Os campos foram organizados para facilitar o preenchimento e reduzir esquecimento de algum dado no parecer.

  4. Gere o documento

    5. Após concluir o preenchimento, confira todos as informações e utilize a opção disponível para gerar o documento. Após a geração do PDF, os campos do formulário serão automaticamente limpos para permitir um novo preenchimento. Caso seja necessário manter as informações, salve o documento antes de iniciar outro processo.

    Ao abrir a janela para a impressão do pdf, não esqueça de desativar as informações de cabeçalho e de rodapé. Importante, também, colocar no formato "Salvar como pdf" para facilitar a cópia de dados no setor de Portarias.

Funcionalidades Disponíveis

Atualmente o sistema disponibiliza:

  • modelos padronizados de pareceres;
  • formulários eletrônicos;
  • automatização do formulário de Certidão de Tempo de Contribuição (CTC);
  • navegação organizada por assunto;
  • interface responsiva para diferentes dispositivos.
Recomendações
  • Confira sempre os dados informados antes de emitir o documento.
  • Utilize a versão mais atualizada dos navegadores.
  • Em caso de alterações na legislação ou nos procedimentos internos, verifique se há atualização do sistema.
Atualizações

O sistema encontra-se em evolução contínua.

Novas funcionalidades poderão ser incorporadas visando aperfeiçoar os processos administrativos e atender às necessidades da Coordenação de Concessões, Aposetandorias e Ações Judiciais.
